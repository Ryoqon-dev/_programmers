## 문제별 풀이

### 1. 나머지 한 점의 좌표를 구해 직사각형 만들기

축에 평행한 직사각형에서는 같은 x좌표를 가진 꼭짓점이 두 개씩 있고, y좌표도 마찬가지입니다. 세 점의 x와 y를 각각 리스트에 담고 `count()`로 한 번만 등장한 값을 찾았습니다. 예를 들어 x좌표가 `1, 3, 3`, y좌표가 `4, 4, 10`이면 빠진 꼭짓점은 `[1, 10]`입니다.

### 2. 사라진 출석번호 찾기

출석번호가 모두 있을 때의 합은 `n * (n + 1) // 2`입니다. 여기서 `sum(numbers)`를 빼면 빠진 번호 하나가 남습니다. 합만 비교하므로 입력 순서는 결과에 영향을 주지 않습니다.

### 3. 비밀번호의 숫자 합 구하기

문자열을 한 글자씩 확인하고 `isdigit()`이 참인 글자만 `int()`로 변환해 더했습니다. `"hello2026"`에서는 `2 + 0 + 2 + 6 = 10`이고, `"ABC"`처럼 숫자가 없으면 초깃값 `0`을 반환합니다.

### 4. 유연 근무제

1. 희망 출근 시각을 자정부터 지난 분으로 바꾼 뒤 10분을 더해 출근 인정 시각을 구합니다.
2. `(startday + j - 1) % 7 + 1`로 기록마다 요일을 계산하고, 토요일(`6`)과 일요일(`7`)은 건너뜁니다.
3. 평일의 실제 출근 시각도 분으로 바꿔 비교합니다. 인정 시각을 한 번이라도 넘긴 직원은 제외하고, 평일 내내 인정 시각까지 출근한 직원 수를 반환합니다.

희망 시각이 `09:58`이면 `10:08` 출근은 인정되고, `10:09` 출근은 지각입니다.

### 5. 세균 증식

1시간마다 수가 두 배가 되므로 `t`시간 뒤에는 처음 수 `n`에 `2 ** t`를 곱해야 합니다. 정수를 왼쪽으로 한 비트 옮길 때마다 값이 두 배가 되므로 `n << t`로 계산했습니다.

